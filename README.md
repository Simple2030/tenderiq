# מערכת מכרזי רמ״י — איך היא בנויה

מערכת ששולפת מכרזי קרקע עם זוכים מרשות מקרקעי ישראל, ובונה מהם קובץ Excel עם
ניתוח זוכים. כל הנתונים מה־API הרשמי של רמ״י; שום מספר לא מומצא.

## 1. מקור הנתונים

ה־API הציבורי שמשמש את אתר המכרזים של רמ״י:

| מה | כתובת |
|---|---|
| חיפוש מכרזים | `POST https://apps.land.gov.il/MichrazimSite/api/SearchApi/Search` |
| פרטי מכרז וזוכים | `GET https://apps.land.gov.il/MichrazimSite/api/MichrazDetailsApi/Get?michrazID=<מזהה>` |

השרת דורש שלוש כותרות, אחרת הוא מחזיר 403:

```
User-Agent: datagov-external-client
Origin: https://apps.land.gov.il
Referer: https://apps.land.gov.il/MichrazimSite/
```

את המבנה הזה למדנו מקוד פתוח של פרויקט
[barvhaim/remy-mcp](https://github.com/barvhaim/remy-mcp), שממנו לקוחה גם
טבלת קודי היישובים.

## 2. למה GitHub Actions

סביבת העבודה של Claude חוסמת גישה לאתרי `gov.il`. מכונות של GitHub Actions
לא חסומות, ולכן השליפה רצה שם: קובץ `.github/workflows/fetch-rmi-tenders.yml`.

הפעלה: בלשונית **Actions** ברפו, **Fetch RMI Tenders**, ואז **Run workflow**.
הריצה לוקחת כ־3 דקות ושומרת את התוצאה ב־`output/rmi_raw.json`.

## 3. מה ה־workflow עושה

1. **שולף את כל המכרזים שיש להם תוצאות** (`hasResults: true`). השרת מתעלם
   בפועל ממסנני התאריך והסוג, ולכן הסינון נעשה בקוד.
2. **מסנן לפי תאריך ועדה** בטווח שהוגדר (כרגע 1.4.2024 עד 12.4.2026).
3. **ממיין לקטגוריות** לפי קוד סוג המכרז וקוד הייעוד:
   - `KodSugMichraz` 1 — מכרז פומבי רגיל, נכנס ל**יזמות**
   - `KodSugMichraz` 2 או 3 — מחיר מטרה ודיור במחיר מופחת, נכנס ל**מחיר למשתכן**
   - `KodYeudMichraz` 4, 6 או 7 — הנחנו שזה מלונאות, אבל בפועל חזרו מגרשים
     באזורי תעשייה ותעסוקה. לכן הקטגוריה מסומנת **תעשייה/מסחר**.
4. **מושך פרטים מלאים** לכל מכרז, עד 50 לכל קטגוריה, עם השהיה של חצי שנייה בין
   בקשות.
5. **שומר JSON ועושה commit** לרפו.

## 5. בניית ה־Excel — `build_excel.py`

```
pip install pandas openpyxl
python3 build_excel.py
```

- **שורה לכל צמד מגרש וזוכה.**
- **שמות ערים** מתורגמים מ־`KodYeshuv` לפי הטבלה של remy-mcp.
- **עמודת סטטוס** מפרידה זוכים אמיתיים מהודעות מערכת של רמ״י, כמו
  "הצעות לא תקינות" ו"אין הצעות למתחם זה".
- **סיווג חברה מול פרטי**: זוכה נחשב חברה אם יש בשמו סימון בע״מ (בכל צורות
  הכתיבה, כולל `בע''''מ`), מילת ארגון (שותפות, קבוצת...) או מילת ענף (הנדסה,
  יזמות, נדל״ן...). זוכי הגרלות פרטיים מסוננים. יחידים שזכו ב־3 מיליון ₪ ומעלה
  נשמרים בגיליון נפרד, כי הם רוכשי קרקע ולא זוכי הגרלה.
- **גיליונות**: סיכום, כל הזכיות (חברות), מחיר למשתכן, יזמות, תעשייה־מסחר,
  ניתוח יזמים, יחידים בסכום גבוה.

## 6. מגבלות ידועות

- **נשלפו 106 מתוך 592 מכרזים בטווח**, בגלל התקרה של 50 לקטגוריה. הסרת התקרה
  ב־workflow תביא את כולם (ריצה של כ־10 דקות).
- **קוד הייעוד של מלונאות לא ידוע.** כדי למצוא אותו צריך את טבלת הקודים של רמ״י.
- **הנתונים הם תמונת מצב** מהריצה האחרונה של ה־workflow, ולא מתעדכנים לבד.
- **Claude לא יכול לדחוף קוד לרפו** עד שמותקנת Claude GitHub App:
  https://github.com/apps/claude/installations/select_target. בלי זה, כל קובץ
  שנוצר בסביבה של Claude נמחק כשהסביבה מתאפסת.
